Trafilatura (Apache-2.0)
------------------------

Trafilatura Core's TypeScript implementation is derived from Trafilatura, by
Adrien Barbaresi and the Trafilatura contributors. Its native Python implementation
translates that TypeScript source. Files containing derived expression carry a header
naming the exact upstream revision and source path, and state how the port was
modified.

Source revision:
https://github.com/adbar/trafilatura/tree/c1bc9531a2a978326112ca9987e1382745116136
(version 2.2.0)

DOI: 10.5281/zenodo.3460969

Ported areas include extraction settings, text utilities, XPath rules,
htmlprocessing (including its XML-to-HTML output mapping), main extraction,
baseline recovery, extraction orchestration, selected tree/parser/option
semantics, and the metadata and cleaning-policy modules.

The pinned Trafilatura source attributes `trafilatura/xml.py::delete_element`
to lxml's `lxml.html` helper at the following link, which is retained verbatim
as upstream attribution rather than treated as an unpinned implementation
authority:
https://github.com/lxml/lxml/blob/master/src/lxml/html/__init__.py

go-trafilatura (Apache-2.0)
---------------------------

go-trafilatura supplied the DOM/HTML translation pattern used when expressing
Trafilatura's lxml XPath rules as per-rule predicate functions. No go-trafilatura
rule body, constant, or threshold is reproduced, and where it encodes an older
Trafilatura release the pinned Python revision above governs.
